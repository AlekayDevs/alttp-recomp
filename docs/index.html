How to start

Cómo empezar

  1. Download the package for your system and open it.
  2. Choose your ROM: The Legend of Zelda: A Link to the Past, USA version, CRC32 777AAC2F (.sfc or .smc).
  3. Play. The first time the game is prepared on your device (a few seconds); after that it opens straight away. The ROM never leaves your device.
  1. Descarga el paquete de tu sistema y ábrelo.
  2. Elige tu ROM: The Legend of Zelda: A Link to the Past, versión USA, CRC32 777AAC2F (.sfc o .smc).
  3. Juega. La primera vez el juego se prepara en tu dispositivo (unos segundos); después abre al instante. La ROM nunca sale de tu dispositivo.

Is the download safe? Each release has a SHA256SUMS file. The launchers and the Android app check it themselves before installing an update; you can also check it by hand with sha256sum. The source is on GitHub and the packages are built from it.

¿Es seguro? Cada release lleva un fichero SHA256SUMS. Los lanzadores y la app de Android lo comprueban solos antes de instalar una actualización; también puedes comprobarlo a mano con sha256sum. El código está en GitHub y los paquetes se construyen desde él.
